มาตรฐานกลาง (ทุกเส้น): Base URL /api/v1 · Auth: ผ่าน BFF ระบบ SBP เดิม — SBPGI ตรวจ x-api-key + user context header (x-user-id/x-user-group-id/x-user-permissions) · เส้น callback ภายนอกใช้ API key/service token · กลุ่ม Auth/สิทธิ์เมนู และเส้นผู้ปฏิบัติงาน ตัดออก — ใช้ระบบ SBP เดิม (Cognito + BFF + auth-backend · ตัดสินใจ 2026-08-05; sidebar/สิทธิ์ใช้ BFF /menus + /groups/current-user/permissions) · แบ่งหน้า ?page=1&size=20 ตอบ {"page","size","total","items":[]} · Error ตอบรูปแบบเดียวกันทุกเส้น: {"code":"DOC_409","message":"ข้อความภาษาไทยตรงตาม SRS"} — ข้อความ popup ต้องตรงตัวตามเอกสาร · วันที่และเลขเอกสารเป็น ค.ศ. ทั้งหมด (payload ISO-8601 ค.ศ. · docNo = YYYY/xxxxx ค.ศ.) ตามระบบ K2 เดิมและระบบ SBP ปัจจุบัน · code namespace แยกกันชัดเจน: roleCode = RBAC role, sectionCode = workflow section, statusCode = document status lookup · ref ที่มา: FGI/FCS เอกสาร Batch v4.0 · K2 SRS v3.1 · ใหม่ เพิ่มในระบบใหม่ · ผสม — ดูภาพรวมที่ Flow FGI/FCS + K2 · ตารางที่ DB รวม
Batch Job scope note: กลุ่ม Batch Job Admin ในหน้านี้เป็น endpoint reference สำหรับ FE Batch Monitor เฉพาะ 2 tab คือ แบบฟอร์มพารามิเตอร์ และ ประวัติการรัน. ไม่ออกแบบ tab Flowchart การทำงาน, งานที่ต้องทำแบบ step-by-step, หรือ Database ที่ใช้ของ batch job ในหน้านี้; รายละเอียดเหล่านั้นให้ดูเอกสาร BE/Runbook/Database reference แยก
