## คุณภาพข้อมูลที่วัดได้ — ข่าวดีเป็นส่วนใหญ่

### ✅ เลขเอกสารสะอาดมาก

```
เอกสาร 18,007 ฉบับ · ไม่ซ้ำเลยสักฉบับ · รูปแบบผิด 0 · ปี 2019–2026 เป็น ค.ศ. ทั้งหมด
ความยาวรหัสร้าน 5 หลักครบทุกแถว (ยกเว้น 1 แถวที่เป็น NULL)
ความยาวทุกคอลัมน์ข้อความ **อยู่ในเพดานของ VARCHAR ปลายทาง** — ไม่มีแถวไหนยาวเกิน
```

### 🔴 กับดักการโหลดที่ต้องรู้

**NULL ในไฟล์ CSV เขียนเป็นข้อความ `NULL` ไม่ใช่ช่องว่าง** — นับจากไฟล์จริง:
ข้อความ `'NULL'` **402,672 ช่อง** · ช่องว่างจริง `''` **6,947 ช่อง** — **คนละความหมาย ต้องแยก**

→ ทุกคำสั่งโหลดจึงใช้ `WITH (FORMAT csv, HEADER true, NULL 'NULL', ENCODING 'UTF8')`
ตรวจหลังโหลดแล้ว: `comp_store_type_code` เป็น NULL จริง 18,007 แถว · เป็นสตริง `'NULL'` **0 แถว** ✅

**ไฟล์เป็น UTF-8 with BOM + CRLF** — ต้องอ่านด้วย `utf-8-sig`

### 🔴 บั๊กในตัว generator เองที่เจอตอนรันจริง

`CommonConfig` มีคอลัมน์ชื่อ **`Group`** ซึ่งเป็น **คำสงวนของ PostgreSQL** →
`syntax error at or near "group"` ตอน `CREATE TABLE`
แก้โดย **ครอบ identifier ทุกตัวด้วย double quote** (ปลอดภัยกว่าไล่ดักเป็นราย ๆ)
